# Personal Portfolio Website

## Project Description

This is my personal portfolio website developed as part of Task 1:
Foundation & Environment Setup.

The project demonstrates the basic concepts of HTML5, CSS3,
JavaScript, PHP and MySQL.

## MySQL Features

The project uses MySQL to store contact messages.

Database operations include:

- Create
- Insert
- Select
- Update
- Delete

The `contacts` table contains:

- id
- name
- email
- message

The `id` column is used as the primary key.

## CRUD Functionality

The contact management system supports:

### Create

Users can submit a contact form and store their message
in the MySQL database.

### Read

Saved contact messages can be viewed using `view.php`.

### Update

Existing contact messages can be edited and updated.

### Delete

Existing contact messages can be deleted.
